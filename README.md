# 🏡 Nestify

A modern **property listing web application** that allows users to explore, create, and manage listings for rentals or real estate. Built using **Node.js**, **Express**, **MongoDB**, and **EJS**, Nestify provides full **CRUD functionality**, secure **authentication & authorization**, and features like **category filtering**, **search**, and **user reviews**.

---

## 🚀 Features

* 🏠 **Listings CRUD:** Create, read, update, and delete property listings.
* 🔐 **Authentication & Authorization:** Secure login and access control using **Passport.js** (or similar).
* ⭐ **Review System:** Add, edit, or delete reviews for each listing.
* 🧭 **Category Filters:** Browse properties by category (beach, city, mountain, etc.).
* 🔍 **Search Functionality:** Quickly find listings using keywords.
* 📱 **Responsive UI:** Built with **Bootstrap** for mobile-friendly design.
* 💾 **MongoDB Integration:** Efficient and scalable data storage.
